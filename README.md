# ⚡ Minecraft-world-panel (Mineflayer Web UI)

Современная веб-панель администратора для Minecraft мира на базе **Node.js**, **Mineflayer** и **Tailwind CSS**. Панель предоставляет удобный интерфейс для мониторинга игроков, управления миром и отправки команд от имени бота в реальном времени.

---

## 🚀 Основные возможности

- **⚡ Интерактивная консоль:** Отправка любых команд от имени бота в реальном времени.
- **👥 Мониторинг игроков:** Автообновление списка онлайна и отображение скинов через Minotar API.
- **🌍 Управление миром:** Удобное переключение времени суток, погоды и игровых правил (`gamerules`).
- **🛠 Генератор команд (Билдер):** Простой конструктор для выдачи предметов, спавна мобов и наложения эффектов.

---

## 🛠 Технологии

- **Backend:** Node.js, Express, Mineflayer, CORS
- **Frontend:** HTML5, Tailwind CSS, JavaScript (Vanilla), FontAwesome
- **Автоматизация:** Батник (`start.bat`) для запуска сервера и открытия интерфейса в один клик.
